# 🧠 Modelos Treinados

Os modelos treinados desenvolvidos durante a Fase 4 do projeto CardioIA Vision foram disponibilizados em uma pasta compartilhada no Google Drive.

Devido ao tamanho dos arquivos `.keras`, eles não foram armazenados diretamente neste repositório GitHub.

## 📂 Modelos Disponíveis

- CNN Própria (`cnn_model_fase4.keras`)
- ResNet50 com Fine Tuning (`resnet50_finetuning.keras`)
- VGG16 (`vgg16_cardioia_model.keras`)

## 🔗 Acessar Modelos

[📁 Abrir Pasta de Modelos no Google Drive](https://drive.google.com/drive/folders/1EUozAz7xARDM7x4axd_glI4zG7Ph4BjI?usp=drive_link)

## 📋 Observação

Os modelos foram treinados utilizando o dataset ECG Images Dataset of Cardiac Patients e empregados nas análises descritas no relatório completo da Fase 4.

O modelo selecionado para compor o protótipo CardioIA Vision foi o **VGG16**, por apresentar o melhor desempenho geral entre as arquiteturas avaliadas.
